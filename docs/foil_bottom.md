# 電極箔の下端輪郭計測

## 何を測るか

動画に写る箔の下端を列ごとに検出します。得られた位置に直線を当てはめ、指定したX位置でのY座標を「代表下端位置」とします。画像は右向きをX正、下向きをY正として扱います。

検出した点は線からの残差を計算し、輪郭の凹凸と直線からのずれを評価します。直線の角度は `angle_deg`、輪郭の近似残差の二乗平均平方根は `straightness_rms_px` です。`peak_to_peak_px` は採用した点の残差の最大値と最小値の差です。

初回の有効な画像位置を基準にする場合、`shift_px = edge_y_px - baseline_y_px` です。実寸の分解能が設定されていれば `shift_mm = shift_px × mm_per_pixel` となります。

## 検出の仕組み

1. 必要ならレンズひずみ・射影変換を適用します。
2. ROI内をグレースケール化し、ガウシアンフィルタで平滑化します。
3. Sobelの縦方向微分から、箔の下端に対応する正負の勾配を選びます。
4. X方向に一定間隔で走査し、強度が基準値を超えた位置を探します。
5. 前フレームに有効な下端があれば、その近傍にある候補を優先します。
6. 各列の候補をサブピクセル補間し、外れ値を除いて直線を当てはめます。
7. 下端位置・角度・輪郭のばらつき・基準からの位置ずれを記録します。

サブピクセル補間を含みますが、その数値精度が測定精度を保証するものではありません。実際の分解能や光学的なぼけ、照明条件の検証が必要です。

## GUIで指定できる項目

| 設定 | 内容 | 既定値 |
| --- | --- | --- |
| ROI | 箔の下端を含む矩形 | 全画像 |
| 明暗 | 明るい箔／暗い箔 | 明るい箔 |
| Gaussian平滑化 | 奇数カーネルサイズ | 5 |
| Sobelカーネル | 縦方向勾配 | 3 |
| 最小勾配 | エッジとして扱う輝度勾配の閾値 | 40 |
| 列間隔 | X方向に点を取る間隔 | 4 px |
| 追跡範囲 | 前フレームに対して探すY方向の距離 | 40 px |
| 有効列率 | 検出に必要なX列の割合 | 0.60 |
| 外れ値許容 | 直線からの許容残差 | 6 px |
| 代表X位置 | 代表下端位置を算出するX座標 | ROI中央 |
| 基準Y位置 | 最初の有効フレーム、Nフレーム平均、固定値 | 最初の有効フレーム |
| 輪郭点の保存 | `contour_points.csv` を保存 | OFF |

前フレームの近傍で線が見つからない場合は、その列を欠測にします。誤検出を防ぐ一方で、実際の箔が瞬間的に大きく移動すると無効フレームが増える可能性があります。

## 出力

`measurements.csv` は1フレーム1行です。主な項目は `valid`、`coverage`、`edge_y_px`、`edge_y_mm`、`baseline_y_px`、`shift_px`、`shift_mm`、`angle_deg`、`straightness_rms_px`、`peak_to_peak_px`、`fit_inliers` です。

`contour_points.csv` はオプションです。検出列のX・Y座標、近似直線のY座標、残差、勾配強度、採用可否をフレームごとに記録します。長い動画ではファイル容量が増えるため、標準では保存しません。

`manifest.json` は元動画のファイルハッシュ、校正パラメータ、解析設定を保存します。確認動画はエッジ重畳結果を確認する用途です。計測値の再計算には元動画と保存された校正・設定を使ってください。

## 再利用上の注意

同じROIと条件を別の映像に適用する場合は、解像度・撮影範囲・カメラ姿勢が同じか確認してください。基準にしている端がフレームをまたいで同じ物理的な部分かも重要です。連続的に搬送される異なる箔の端を測る場合、時系列の変動は同じ物体の追跡結果とは限りません。
