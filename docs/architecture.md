# 実装の分担

校正・補正・計測・保存を別々の責務として扱います。

- `calibration.py`: 校正用動画や画像から、後で再利用するパラメータを推定します。
- `processing.py`: 保存したパラメータで画像を補正します。計測モジュールを実行し、出力を保存します。
- `analysis.py`: 入力画像から目的の計測値を取得します。校正計算は行いません。
- `io.py`: ファイル形式の差や保存履歴を扱います。
- `cli.py` / `gui.py`: 入力条件の受付だけを行い、同じエンジンを利用します。

## 座標系

1. 元画像座標（px）
2. レンズ補正済み画像座標（px）
3. 射影変換済みの平面画像座標（px）
4. 平面実寸座標（mm）。射影変換済み画像では、`1/pixels_per_mm` で換算できます。

校正によって使用する座標系が異なります。射影パラメータがレンズ補正済み画像を前提とする場合、対応するレンズ校正なしでは処理を停止します。

## トレーサビリティ

`manifest.json` に校正スナップショット、元データのファイル名とSHA-256、処理設定、出力を記録します。保存した確認動画は目視用です。再処理するときは元動画と同じ設定を使用してください。動画の再エンコード条件とバージョンも合わせる必要があります。
